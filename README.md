Liq POS System
A Point of Sale System built with Python and PostgreSQL for managing inventory, sales and generating reports.

Features
Inventory Management - Update and track product inventory in real time
Sales Processing - Record and manage sales transactions
Reports Generation - Generates comprehensive and inventory reports 
User Authentication - Secure login system for authorized access

Tech Stack
Frontend - Python GUI for custom graphical user interface built with Python 
           Intuitive and User friendly interface for daily operations

Backend - PostgreSQl for a robust and relational database for data storage 
          Initial data imported from Excel spreadsheets
